# Code of Conduct

## Our Standard

We welcome thoughtful, constructive participation. Treat people with respect, assume good intent, and focus criticism on ideas and code rather than individuals.

## Unacceptable Behavior

Harassment, discrimination, threats, personal attacks, doxxing, and disruptive behavior are not acceptable.

## Enforcement

Report concerns privately through the repository's GitHub contact or Security Advisory workflow. Maintainers will review reports confidentially and may remove content or restrict participation when necessary.
