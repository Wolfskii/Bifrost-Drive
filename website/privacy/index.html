Privacy Policy

Effective August 29, 2026

This Privacy Policy explains how Webble — Bifrost Drive (“Bifrost Drive,” “we,” “us,” or “our”) handles information when you use the Bifrost Drive desktop application and this website.

1. Summary

Bifrost Drive is a desktop application that connects your computer directly to storage services you choose. We do not operate a cloud relay that receives your files, credentials, or Google Drive content. The public website is static and currently uses no analytics, advertising trackers, accounts, or marketing cookies.

2. Information handled by the desktop application

Account credentials and tokens

Credentials, OAuth access tokens, and OAuth refresh tokens are stored on your device using the native credential service available to Bifrost Drive: Windows Credential Manager, macOS Keychain, or Linux Secret Service. Bifrost Drive does not store secret values in its SQLite database.

Connection and file information

The app stores non-secret connection settings, provider type, remote paths, file metadata, transfer state, activity history, cache records, pins, and conflict records locally on your device. File content may be cached locally when needed for hydration, offline access, transfer, or a filesystem operation you request.

Logs

Bifrost Drive is designed not to log passwords, OAuth tokens, private keys, credentials, or file contents. Diagnostic messages may describe an operation, provider, remote path, or error without including secret material.

3. Google user data

When you connect Google Drive, Google provides Bifrost Drive with authorization tokens after you approve access. Bifrost Drive uses Google Drive data only to provide user-facing storage functions you request, including listing files and folders, reading and writing file content, creating folders, renaming, copying, deleting, reporting storage quota, synchronizing, and mounting the connection in your operating system.

Google Drive tokens are stored only in your device’s native credential service. Google Drive file content and metadata travel directly between your device and Google’s APIs, except for local cache and metadata needed to provide the requested desktop features. We do not sell Google user data, use it for advertising, or transfer it to data brokers.

When you connect Google Photos, Bifrost requests access only to media and albums created through Bifrost. Google Photos tokens are stored only in the same native credential service. Media content and metadata travel directly between your device and Google’s APIs, except for local cache and metadata needed to provide the requested desktop features. Bifrost does not use Google Photos data for advertising, sale, or generalized artificial-intelligence or machine-learning training.

Bifrost Drive’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

When you open a Google Docs, Sheets, or Slides file in an operating-system application, Bifrost Drive temporarily provides an exported DOCX, XLSX, or PPTX copy to that application. If you edit and save the copy, Bifrost Drive imports the changed content into the original Google Workspace file. Opening a file without saving changes does not upload or modify the Google file. In browser mode, Bifrost Drive provides a read-only shortcut to the Google editor instead.

Webble employees, contractors, and service providers do not routinely read Google user data. Exceptional access is limited to security investigations, legal compliance, or specific support that you authorize.

Google user data is not sold, used for advertising, or used to train or improve generalized artificial intelligence or machine-learning models.

4. Website information

This website is served as static files. It does not intentionally collect form submissions, create user accounts, run analytics, or set marketing cookies. Standard infrastructure logs may be generated by the hosting provider or reverse proxy and can include IP address, timestamp, requested URL, browser information, and response status for security and operational purposes.

The download button requests public release metadata and downloads from GitHub. GitHub may process information under its own privacy policy when you follow those links or download a release.

5. How information is shared

The app communicates with storage providers you configure and with GitHub for update checks and downloads. We may disclose Google user data only to provide or improve the requested Bifrost features, for security or abuse prevention, or to comply with law. We do not sell personal information or transfer Google user data to advertising platforms, data brokers, or information resellers. A merger, acquisition, or sale of assets involving Google user data will require explicit prior user consent where required by Google policy.

6. Retention and deletion

Local configuration, metadata, history, cache files, and credential references remain on your device until you remove them. Removing a connection deletes its database record and native credential entry where the operating system permits it, but may not remove unrelated application history or cached files automatically. The uninstaller's local-data option removes the user data it covers; the operating system application-data directory may require separate manual removal. Temporary exported files are removed when their filesystem handles close. You can revoke Bifrost Drive’s Google access at any time from your Google Account security settings.

7. Security

We use platform credential stores, TLS certificate validation, SSH host verification, scoped application capabilities, secret redaction, and signed update mechanisms where available. No software can guarantee absolute security, and you are responsible for securing your device and storage-provider accounts.

8. Children

Bifrost Drive is not directed to children under 13, and we do not knowingly collect personal information from children through this website.

9. International processing

Your storage provider, GitHub, hosting provider, and operating-system services may process information in countries other than your own under their respective terms and policies.

10. Changes to this policy

We may update this policy as the product changes. The effective date above will be revised when material changes are published. If we change how Bifrost Drive uses Google user data, we will update this policy, notify affected users, and request renewed consent before using Google data for the new purpose.
