# Testing

Rust unit tests cover path normalization, capabilities, state transitions, retry decisions, cache eviction, durable transfer recovery, synchronization persistence, conflict detection, metadata, FTP/FTPS endpoint validation, SMB endpoint validation, and FUSE boundaries. `task test:connections` exercises provider contracts against real local services: MinIO and Adobe S3Mock for two independent S3 implementations, Apache for WebDAV, atmoz SFTP with generated known_hosts and ephemeral Ed25519 key files, vsftpd for FTP, and Samba for SMB. The task removes all fixture containers and volumes after success or failure.

Immich has a separate opt-in Docker contract because its official stack is substantially heavier than the protocol fixtures. `task test:immich` starts the official Immich server with Redis and vector-enabled Postgres, initializes a fresh admin account, creates a temporary full-permission API key through the Immich API, and verifies Bifrost authentication, root/photo/album listing, and storage capacity. The task removes the Immich containers and volumes after success or failure. Override `IMMICH_VERSION` to test a specific official Immich image tag and `IMMICH_PORT` if port 2283 is unavailable.

Google does not publish a Google Drive API emulator. Backlot exposes a useful read-only Drive-shaped corpus API, but its current surface does not implement Bifrost's writable create, media upload, update, delete, and copy contract. Google Drive provider behavior therefore uses deterministic unit tests for request-independent mapping and requires a separate opt-in live Google account acceptance suite for full API compatibility. A future local Drive fixture should be Bifrost-owned and stateful rather than treating a Google Cloud Storage emulator as Google Drive.

Frontend tests use Vitest and component testing. Windows CFAPI behavior requires native Windows 11 22H2+ tests on NTFS, including Explorer-facing install, hydration, local edits, recovery, and uninstall. CI must clearly distinguish compile checks from native integration tests.
