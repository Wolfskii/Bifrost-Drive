# Getting Started

1. Install the prerequisites in [development.md](development.md).
2. Run `task setup`.
3. Run `task check` to compile the workspace and frontend.
4. Run `task dev` to open the desktop shell.
5. Run `task docker:up` when exercising provider integration tests.

The current build is an early foundation. The UI shell is functional, while S3 connection behavior, Windows CFAPI integration, cache, transfers, and synchronization are still under development.
