# S3

The S3 adapter is the first implemented provider slice. It supports AWS SDK-compatible endpoints such as MinIO through explicit endpoint, region, bucket, and path-style configuration. The current implementation has been exercised against MinIO for connection testing, listing, streamed upload, range download, stat, and delete.

Paginated listing, metadata, range reads, streamed writes, and loading stored credentials into S3 provider sessions are implemented. Multipart uploads, checksums, and versioning remain Planned. The Compose MinIO service uses development-only values from `.env.example`.
