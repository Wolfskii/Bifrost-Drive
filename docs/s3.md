# S3

The S3 adapter is the first implemented provider slice. It supports AWS SDK-compatible endpoints through explicit endpoint, region, bucket, and path-style configuration. The provider contract runs against both MinIO and Adobe S3Mock for connection testing, listing, streamed upload, range download, stat, and delete without requiring an AWS account.

Paginated listing, metadata, range reads, streamed writes, and loading stored credentials into S3 provider sessions are implemented. Multipart uploads, checksums, and versioning remain Planned. The Compose MinIO service uses development-only values from `.env.example`.
